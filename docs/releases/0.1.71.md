# EverythingMac 0.1.71

## Changes

- A damaged or incomplete saved index is detected when the app opens it and is rebuilt with a scan, instead of blocking the app or making it hang or use huge amounts of memory.
- If updating the index fails, the app rescans automatically instead of stopping with an error until it is relaunched.
- A problem while reading file sizes and dates in the background no longer quits the app or leaves "Indexing file sizes and dates…" showing forever.
- After a failed or cancelled rescan, the app no longer starts another one on every update; the status bar shows "Rescan needed" until you choose Rescan.
- The index's temporary file is removed even when the app crashes or is forced to quit.

## Validation

- Passed 1,658 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings. New tests cover damaged index files and panics during updates and background indexing; a one-off run of 20,000 randomly damaged indexes found no crash.
- Opening a 4.6-million-entry index takes about 4.5% longer because of the new checks.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks. The live check now also rebuilds a damaged index.
