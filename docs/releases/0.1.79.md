# EverythingMac 0.1.79

## Changes

- Cancelling the first scan, or the rebuild of an index that could not be read, no longer leaves the app on "Initializing". The status bar shows **No index**, and Rescan builds one.
- When the index needs a rescan that cannot start automatically, the status bar now says **Rescan needed** instead of "Ready". Opening another index resumes automatic rescans.
- Results stay usable while an automatic rescan runs.
- Messages about file actions, such as a partial move to the Trash, no longer disappear right away. They stay until you dismiss them or search again.
- Live Updates paused from the Index menu stay paused through rescans, as the user guide says.
- Touching the monitored root folder, or changing its permissions or Finder tags, no longer starts a full rescan.
- Files inside folders EverythingMac cannot open are no longer added to the index when they change.

## Validation

- Passed 1,624 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings; the engine and bridge tests also passed under Guard Malloc. New tests cover changes to the root folder and to folders the app cannot open.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks, including new steps for a cancelled rebuild, paused Live Updates, and messages kept through background refreshes.
