# EverythingMac 0.1.74

## Changes

- The app no longer grows the longer it runs. Before, it kept the name of every file it had ever seen until it quit, even after the file was deleted, so build folders, caches, and temporary files added about 5 MB for every 100,000 new file names.
- Opening the index is faster and uses less memory: 1.26 seconds instead of 1.75 and about 60 MB less for 4.6 million items on an Apple M4 Pro.
- Full scans use about 175 MB less memory at their peak.
- Live updates add large folders with shorter pauses: a folder with 200,000 files held searches for at most 60 ms instead of 85–90 ms.

## Validation

- Passed 1,612 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings; the engine and bridge tests also passed under Guard Malloc, which crashes on any use of freed memory. A new test makes random file changes and checks after each one that every name is kept exactly as long as an item uses it.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks.
