# EverythingMac 0.1.72

## Changes

- After a scan, file sizes and dates are read in about half the time: about 20 seconds instead of 40 for 3.7 million files on an Apple M4 Pro. "Indexing file sizes and dates…" disappears sooner, and sorting or filtering by size or date is complete sooner.
- Searches stay as fast while sizes and dates are being read.

## Validation

- Passed 1,660 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings. New tests cover reading in batches and ignoring a read for a file that was removed or replaced meanwhile.
- On a copy of a 4.6-million-entry index, the new version read the same sizes and dates as the previous one.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks.
