## Changes

- Remove automatic search suggestions; saved searches and recent history remain available through the Search Library button.
- Remove the full-path popup when hovering over file rows.
- Rename local targets, crates, build tools, and remaining app branding to EverythingMac. Upstream attribution and compatibility references are preserved.
- Migrate existing indexes from `cardinal.db` to `everything-mac.db` on normal startup. Read-only diagnostics leave the original file unchanged, and migration never overwrites an existing renamed index.

## Update

```sh
brew update
brew upgrade --cask seedds/tap/everything
```
