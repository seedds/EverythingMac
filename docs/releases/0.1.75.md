# EverythingMac 0.1.75

## Changes

- Large file changes no longer pause searches. While a big folder is copied in, moved, or deleted, a search or scroll now waits at most about 15 ms for the index to update, instead of up to a fifth of a second.
- Many new files in a large folder are indexed much faster: 10,000 files created in a folder of 100,000 took 2.5–4 seconds instead of 15, and the app no longer stays busy all that time.
- When macOS asks the app to recheck a folder, only what changed is updated. An unchanged folder of 200,000 files takes 5 ms instead of about 230 ms, and its files stay selected however many are selected.

## Validation

- Passed 1,616 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings; the engine and bridge tests also passed under Guard Malloc. New tests apply large changes one step at a time, with files removed by the app in between, and check after every step that the index is complete and consistent.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks.
