# EverythingMac 0.1.69

## Changes

- Searches now match file and folder names and paths only. They never open files or read their contents or Finder tags.
- The `content:` and `tag:` filters are removed, along with Everything filters that EverythingMac never supported, such as `artist:`, `dupe:`, `attrib:`, `da:`, and `case:`.
- Text with a colon that is not a supported filter, such as `content:invoice`, is now matched against names like any other word, instead of reading files or showing an error.
- The supported filters are unchanged: `file:`, `folder:`, `ext:`, `type:`, `audio:`, `video:`, `doc:`, `exe:`, `size:`, `dm:`, `dc:`, `parent:`, `infolder:`, `nosubfolders:`, and `regex:`.

## Validation

- Passed 1,644 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings. New tests check that unsupported filter names parse as words and match names, not file contents.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks.
