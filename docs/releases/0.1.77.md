# EverythingMac 0.1.77

## Changes

- If macOS discards its record of file changes, as it can after a disk repair or a reinstall, EverythingMac now notices on the next launch and rescans. Before, changes made while the app was not running could stay missing from the index until you rescanned yourself.
- An index copied from another Mac is also rescanned instead of being updated with this Mac's file changes.
- Indexes saved by earlier versions keep working and are upgraded automatically. Versions before 0.1.77 cannot read indexes saved by this version and rebuild them.

## Validation

- Passed 1,621 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings; the engine, bridge, and file-event tests also passed under Guard Malloc. New tests open indexes saved with the current, a missing, and a different record of file changes, and check which are rebuilt.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks.
