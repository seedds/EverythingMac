# EverythingMac 0.1.73

## Changes

- Full scans are about a third faster: scanning a 5-million-item startup disk takes about 11 seconds instead of 15–16 on an Apple M4 Pro. This speeds up the first scan, rescans after changing the scope, and rebuilding a damaged index.
- Exclusion patterns no longer slow scans down; with four patterns, a scan takes about 10.5 seconds instead of 16.
- A scan uses less memory at its peak, and the finished index uses about 30 MB less.
- Large changes picked up by live updates, such as moving a folder with 200,000 files, are indexed sooner.

## Validation

- Passed 1,662 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings. New tests check that walks exclude the same entries as the full exclusion check and that the name index built in bulk matches one built entry by entry.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks.
