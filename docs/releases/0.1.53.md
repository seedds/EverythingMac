## What's new

- Exclude directory names and glob patterns throughout the index, including explicitly included folders. Validate rules in Preferences and save with a rebuild.
- Searchable, offline **Search & Shortcuts** help, available with Command-/.
- A configurable global activation shortcut, with conflict detection, Disable, and Restore Default actions.
- Persistent recent searches and saved searches that restore the query, folder scope, and case sensitivity together, plus type-ahead suggestions.

## Index compatibility

This version reads existing v7 indexes and writes v8 checkpoints to store exclusion rules. Older app versions cannot read v8 indexes; use 0.1.53 or later after upgrading. No initial index rebuild is required when the indexing configuration is unchanged.

## Install or update

Download the Apple Silicon DMG below, or run:

```sh
brew update

```
