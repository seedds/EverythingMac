# EverythingMac 0.1.82

## Changes

- The results column "Size on disk" is now called "Size". It still shows and sorts by the space each file takes on disk, so sparse disk images show their actual usage. `size:` search filters still compare logical file size, as the search help explains.

## Validation

- Passed the saved-index, sort, live, and feature checks; the saved-index check confirms the Size column's title and its on-disk sizes. Rust code is unchanged.
