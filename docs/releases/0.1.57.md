## Changes

- Adopt SwiftUI's application lifecycle, with SwiftUI managing the main search window and standard app menus.
- Open Settings in a separate native window through the gear button or Command-comma, allowing search to remain usable while settings are open.
- Discard unsaved settings when the window closes and reload current preferences when it reopens. Saving settings preserves table layout and sort changes made while the settings window was open.
- Preserve the existing NSTableView results table and search engine, global activation shortcut, menu bar icon, Quick Look, and index saving before quitting.
- Keep close-to-hide behavior, restore minimized windows on activation, and retain the Command-W close shortcut. Dock reopening restores the existing search window.
