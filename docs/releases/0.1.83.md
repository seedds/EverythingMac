# EverythingMac 0.1.83

## Changes

- Folders whose details macOS withholds, such as some system folders in `/private/var` and `/Library/Caches`, are indexed as folders instead of files, so `folder:` finds them and `file:` no longer lists them. They show no dates. An existing index corrects them with Index → Rescan, or when the folder that holds them changes.
- When reading a changed folder stops responding, as a cloud storage folder can when its provider hangs, other live updates no longer wait behind it. After 10 seconds without progress, EverythingMac applies the other changes and reads that folder again once it responds.
- In an index saved by an older version that listed a folder twice, items added inside that folder are found by name, and removing them no longer starts a full rescan.
- The performance guide's build commands use the current package name.

## Validation

- Passed 1,635 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings; the engine and bridge tests also passed under Guard Malloc. New tests cover folders whose details cannot be read (in full scans, live updates, and older indexes), a folder walk that stops reading, and items at the same path as another.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks. The feature check timed out once and passed twice on rerun, as it did on 0.1.81 earlier the same day. A fresh index of `/private/var/db` lists `DifferentialPrivacy` and `CoreDuet/Knowledge`, which macOS protects, under `folder:`.
- Adding 10,000 items whose name 46,046 items already had took 3.8 µs each in a 5.7-million-item index, so that was left unchanged.
