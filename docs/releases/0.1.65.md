# EverythingMac 0.1.65

## Changes

- Pressing F8 now removes trashed files from the results almost immediately. The files were already moved to the Trash quickly, but their rows stayed in the list for about a second and a half while the app waited for macOS to report the change. The app now updates its index for the files it trashed right away and refreshes the results at once.
- The Trash regression check, which had timed out since 0.1.57 because it waited for a status message that was replaced within milliseconds, now waits for the action to finish and passes. It also measures how quickly trashed files leave the results.

## Performance

Measured with the Trash check, from the key press until the rows left the results:

- One file: about 1.5 s in 0.1.64, 14–20 ms now.
- 130 files: 0.5–1 s in 0.1.64, 70–85 ms now.

Moving the files to the Trash itself was unchanged: about 7 ms for one file and under 80 ms for 130.

## Validation

- Passed 1,829 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks.
