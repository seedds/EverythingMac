# EverythingMac 0.1.63

## Changes

- Typing with an input method such as Chinese Pinyin works in the search and folder fields. Previously, app updates while you typed (such as search results or status changes) ended the composition and committed the typed letters, so a character often could not be chosen.
- While an input method is composing text, Return, Escape, and the arrow keys go to the input method instead of starting a search, hiding the window, or moving into the results.
- Text being composed is no longer searched letter by letter; the search runs once a character is chosen.
- The user guide, development guide, performance report, and engineering history now describe the changes from 0.1.56 through 0.1.63, including measurements for live updates, name search, and large selections.

## Validation

- Added a feature check that composes text in the search field through the same text-input calls an input method makes. It reproduced the reset before the fix and passes after it, along with the other 63 feature checks.
- Passed the saved-index, sort, selection, live, tab, and terminal checks and the Rust bridge tests. `--trash-check` times out at step 23, as it does on 0.1.62.
