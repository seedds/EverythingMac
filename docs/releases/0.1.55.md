## Changes

- Speed up case-sensitive exact filename and prefix searches by looking up matching names directly instead of scanning unrelated names.
- Speed up searches within narrower folder scopes by matching filenames inside the scope. Existing matching rules, result order, and live file updates are preserved.
- Reorganize the documentation into a user guide, development guide, performance measurements, and release history. Remove obsolete baseline comparison tools.

## Performance

On a 4.43-million-entry snapshot, median exact filename search time fell from 4.78 ms to 0.31 ms, and prefix search time from 9.60 ms to 0.34 ms. A scoped `rs` search fell from 39.97 ms to 8.78 ms. These measurements include filename sorting and the first 128 results, but exclude index loading, typing delay, and UI rendering. Broad folder scopes may see little change.

No additional persistent index is required for these improvements.
