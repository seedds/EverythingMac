# EverythingMac 0.1.68

## Changes

- Browsing search history with Option-Up and Option-Down no longer reorders it. Pressing Return or moving into the results records the search you chose.
- F2 selects the file name without its extension, so typing replaces only the name.
- Closing Settings while recording a shortcut no longer leaves the recorder listening. Before, a key combination typed afterwards in the search window could replace your global shortcut.
- `content:` and `tag:` results keep a stable order, so rows no longer move around when results refresh.
- With case sensitivity off, `parent:`, `infolder:`, `content:`, and `tag:` ignore case for accented and non-Latin letters too, and folder names match however their accents are encoded.
- Option-Command-C copies paths from the results table, as in the menu, even when the menu item is unavailable.
- Clicking the Dock icon shows the existing window without asking SwiftUI to open another, and results refresh every row the table has prepared, not only the visible ones.

## Validation

- Passed 1,842 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings. New tests cover result order, Unicode case, and accented folder names.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks. New feature checks cover history browsing, the F2 selection, the shortcut recorder after closing Settings, and the copy shortcuts.
