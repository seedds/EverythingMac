# EverythingMac 0.1.84

## Changes

- Dragging a column divider in the results table resizes only that column; the columns after it move over and keep their widths. Before, the Created column grew or shrank with every drag while the columns filled the window.
- Resizing the window no longer changes column widths. A horizontal scroller appears when the columns are wider than the window, and the space after the last column stays empty when the window is wider. Reset Column Widths restores the default widths exactly.
- The user guide explains that when reading a changed folder stops responding, other changes are applied without it and the folder is read again once it responds.

## Validation

- Passed the saved-index, sort, live, and feature checks. The feature check now drags a column divider through the table header and resizes the window; it fails against the old behavior. Rust code is unchanged.
