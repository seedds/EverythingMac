## Changes

- Display and sort by **Size on disk**, including the actual allocation of sparse virtual disk images. `size:` search filters continue to use logical size.
- Fix Command-C, Copy Paths, and Copy Filenames while selection details are loading. Copy waits for the selection and cancels safely if the selection or search changes.
- Speed up selection restoration during live updates in large result sets.
- Open normal development launches through macOS Launch Services to preserve rounded Dock icons.

## Index format

This release uses snapshot format v7. **Indexes from previous versions must be rebuilt**; there is no old-format compatibility layer.

## Validation

921 Rust tests passed across the native bridge, filesystem walker, and search cache. Native selection/copy and sparse-file display checks passed. Release safeguards, shell syntax, and whitespace checks passed. The release workflow verifies the signed app and DMG before publication and derives the Homebrew checksum from the published download.
