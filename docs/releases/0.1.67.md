# EverythingMac 0.1.67

## Changes

- While the search window is hidden, minimized, on another Space, or covered by other windows, the index stays up to date but the displayed search is no longer repeated after every file change. The results update as soon as the window is shown again.
- Moving through results with the arrow keys or clicking rows no longer rebuilds the menus for each row, and the status indicator no longer flickers with each click.

## Performance

- Each Down Arrow in the results uses about 2.8 ms of main-thread time instead of 8.5 ms.
- With a file changing four times a second and the window hidden, the app ran no searches in 30 seconds instead of 8–10, and used 328–386 ms of CPU instead of 809–945 ms.
- Showing the window brings the results up to date in about 100 ms, instead of 0.3–1 s.

## Validation

- Passed 1,837 Rust tests, with the system-wide search cancellation test excluded.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks. The live check now hides the window, changes a file, and confirms that the search runs again only once the window is shown.
- A new idle check measured CPU with the window shown and hidden, and per arrow key.
