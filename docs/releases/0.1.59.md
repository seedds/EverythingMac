# EverythingMac 0.1.59

## Changes

- Indexing file sizes and dates in the background no longer resets the results list about once a second. Rows stay visible while scrolling and selections stay valid. Results sorted or filtered by size or date refresh at most every 10 seconds while indexing runs and once more when it finishes.
- Name sorting stays stable while sizes and dates are indexed. Folders still sort before files with the same name.
- Index saves are written completely and synced to disk before they replace the previous index. A failed save, for example on a full disk, keeps the previous index and reports the error instead of replacing it with a truncated file. Opening an index and quitting without changes no longer rewrites it.
- If File → Open Index… cannot open the chosen file, the current index stays loaded. A live index is saved before switching.
- Open, Reveal in Finder, Quick Look, Rename, Move to Trash, and Terminal wait for a just-clicked selection instead of showing "Selection is loading".
- Move to Trash asks for confirmation above 50 items, skips items inside a selected folder (they go with the folder), and continues past individual failures, reporting how many items were moved.
- File icons appear after reordering columns, Reset Column Widths applies the right width to each column, and icons skipped during fast scrolling load once their rows are visible.
- Fix ownership of the filesystem event stream, recover correctly when live updates stop unexpectedly, and prevent an event path that is not valid UTF-8 from disabling the index.

## Validation

- Passed 1,815 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings.
- Passed the saved-index, sort, selection, feature, live, tab, and terminal checks. `--trash-check` times out at step 23, as it does on 0.1.58.
- On a 4.57-million-entry index, index loading and search times are unchanged.
