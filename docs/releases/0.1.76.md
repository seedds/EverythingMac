# EverythingMac 0.1.76

## Changes

- `exe:` and `type:app` now find apps. Apps are folders on a Mac, so these filters missed them before; `exe:safari` now finds Safari.
- `ext:` and the other categories also match other folders that Finder shows as a single item, such as installer packages and `.rtfd` documents: `doc:` finds `.rtfd` documents, and `ext:app` finds every app.
- Help → Search & Shortcuts describes this.

## Validation

- Passed 1,618 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings; the engine and bridge tests also passed under Guard Malloc. On a 4.6-million-entry index, other filters returned the same results as before, just as fast.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks.
