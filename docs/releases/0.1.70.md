# EverythingMac 0.1.70

## Changes

- `ext:`, `type:`, `audio:`, `video:`, `doc:`, and `exe:` return results much faster on large indexes: 2–3 ms instead of 140–200 ms on 4.6 million entries.
- `size:`, `dm:`, `dc:`, `file:`, and `folder:` return results 5–8 times faster, and an empty search, which lists every file, about 10 times faster.
- Queries that combine results, such as `!a`, `a|b`, and `a b`, are 2–5 times faster.
- Searching with a short folder name in the folder field, which matches many nested folders, takes tens of milliseconds instead of more than half a second.
- Right after a scan, `size:`, `dm:`, and `dc:` read sizes and dates that are not indexed yet in parallel, and the index keeps them.

## Validation

- Passed 1,650 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings. Results were identical to 0.1.69 for 30 measured queries, apart from the order of equal names in `**` queries.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks.
