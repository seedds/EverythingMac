# EverythingMac 0.1.78

## Changes

- File changes take slightly less work to process. The list behind the Events tab is now prepared only when the tab shows it, instead of for every file event: about 5 ms less engine time per 20,000 file changes, for example during a large build or copy.

## Validation

- Passed 1,622 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings; the bridge tests also passed under Guard Malloc. A new test checks that the Events tab lists the newest 500 events, newest first, exactly as before.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks.
