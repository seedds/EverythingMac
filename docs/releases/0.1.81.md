# EverythingMac 0.1.81

## Changes

- Changing thousands of files at once, such as with `chmod -R` or a script that edits each file, no longer makes EverythingMac rescan the whole disk. When macOS drops some of those changes on their way to the app, EverythingMac reads them back from macOS's event history.
- Moving a large selection to the Trash no longer freezes the app before the confirmation appears; checking which items are inside selected folders took up to 19 seconds for a million items and now takes a fraction of a second.
- A rescan stops reading sizes and dates for the index it replaces.
- If EverythingMac's data folder is reached through a symlink, its own saves are no longer indexed, which marked the index as unsaved again after every save.
- Symlinks now count as files in `ext:`, `file:`, and the category filters, instead of matching only until their sizes and dates were read.

## Validation

- Passed 1,631 Rust tests, with the system-wide search cancellation test excluded, and clippy without warnings; the engine and bridge tests also passed under Guard Malloc. New tests cover dropped events, top-level Trash items, the size and date backfill, a symlinked data folder, and symlinks in filters.
- Passed the saved-index, sort, selection, feature, live, tab, terminal, and Trash checks. Appending to 10,000 files at once rescanned every time without the replay and never with it.
