# EverythingMac 0.1.58

## Changes

- Require macOS 14 (Sonoma) or later. Macs on macOS 12 or 13 should stay on 0.1.57.
- Faster, lighter UI: loading rows and file details no longer redraw the whole
  window; only changed table rows update. File details use one filesystem call per
  row, and icons are cached by path.
- Live polling sends the event list only while the Events tab is open and the list
  has changed, and polls less often while the window is hidden.
- Column widths are saved once resizing ends instead of on every step of the drag.
- Native look: system search fields, sort arrows, a highlighted sort column,
  right-aligned sizes and dates, a system status bar with a fixed-width Files/Events
  segmented control, and a native empty-results view. The Events tab is now a native
  table with Open, Reveal in Finder, and Copy Path.
- Settings is split into General, Index, and Privacy tabs. General settings apply
  immediately; index scope changes apply with **Apply & Rebuild**. The search delay
  is now a saved setting, and the terminal app is chosen with a file picker.
- File menu: Open (⌘O), Reveal in Finder (⌘R), Quick Look (⌘Y), and Copy Path (⌥⌘C),
  enabled when the results table has focus. View menu: Files (⌘1) and Events (⌘2).
  Edit menu: Find (⌘F).
- The menu bar icon uses SwiftUI's `MenuBarExtra`.
- Remove the gear and Index details (ⓘ) buttons. Settings opens with Command-comma.
  Live Updates, Rescan (⌥⌘R), and Cancel Scan move to a new Index menu, and the
  status bar shows **Paused** while live updates are off. File → Open Index… (⇧⌘O)
  opens a saved index; the monitor root is chosen in Settings → Index, which also
  shows the index file and status. Hover over the status for index details.

## Validation

- Passed the self, sort, selection, feature, live, tab, and terminal checks and the
  Rust bridge tests. `--trash-check` times out at step 23, as it does on 0.1.57.
